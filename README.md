# To-Do List from Text (PS 46 - Roll No. 46)

## Problem Statement
People write messy notes. Convert free-text notes into a prioritised to-do list with deadlines.

## How to Run
1. Install dependencies:
   `pip install -r requirements.txt`
2. Add `GEMINI_API_KEY=your_key` to a `.env` file (do not upload `.env`).
3. Run the app:
   `streamlit run app.py`
